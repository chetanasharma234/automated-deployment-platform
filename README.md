
# Automated Deployment Platform

## Project Overview
Automated deployment of a Python Flask application
on AWS using DevOps tools.

## Technologies
- AWS EC2
- Python Flask
- Linux Ubuntu
- Git and GitHub
- Terraform
- GitHub Actions
- Nginx
- AWS CloudWatch

## Application Features
- Flask home page
- Application health check
- Automated deployment (planned)
- AWS infrastructure provisioning (planned)

## Run Locally

Install dependencies:

pip install -r app/requirements.txt

Run application:

python app/app.py

Open:

http://127.0.0.1:5000
